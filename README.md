# EV MarketScope

Static EV market dashboard based on the supplied EV dataset and styled around the shared EVMarketScope reference.

## Open

Open `index.html` in a modern browser. The chart data is included in `assets/data/ev-market-data.js`; no build step or server is required.

## Included

- Responsive landing page, project overview, data story and methodology
- Year, market region and vehicle category filters
- Interactive canvas charts and summary metrics computed from 100,000 supplied records
- Original Tableau packaged workbook at `assets/data/EV_Market_Performance_FINAL_07.twbx`

Metrics are computed from the supplied dataset and should be interpreted in that context; they are not independently verified market totals.
